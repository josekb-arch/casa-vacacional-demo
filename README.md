# Casa Ameyalli · Demo de portal de reservas para casa vacacional

Demo para propuesta (Freelancer.com) hecha por Jose Khalili. Contenido, precios y reseñas de ejemplo; imágenes ilustrativas de Unsplash. **No procesa pagos reales.**

Incluye: buscador con fechas y huéspedes, páginas de espacios con galería, amenidades, calendario de disponibilidad con noches bloqueadas (sincronización con Airbnb simulada), flujo de reserva con desglose de precio y pago demo (estilo Stripe / Mercado Pago / PayPal), correo de confirmación, reseñas de ejemplo, mapa, reglas, FAQ, WhatsApp, guía local (SEO) y vista previa del panel del anfitrión (reservas, tarifas y temporadas, cupones, promociones a redes, mensajes y registro de sincronización).

Animaciones: GSAP + ScrollTrigger + Lenis, con soporte para `prefers-reduced-motion`.

Live: https://josekb-arch.github.io/casa-vacacional-demo/
